## 详细说明

### DRV-1 驱动入口（SchneiderDriver）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderDriver.cs`
- **基类**：`ModbusTcpDriver`（来自 NewLife.Modbus）
- **接口实现**：`ILogFeature`、`ITracerFeature`
- **核心行为**：
  - 通过 `[Driver("SchneiderPLC")]` 支持驱动自动发现
  - 重写 `Open()`：调用基类打开 Modbus TCP 连接后，额外调用 `Modbus.Open()` 初始化通道
  - 读写操作继承自 `ModbusTcpDriver`，支持 Modbus 标准功能码
  - 关闭操作继承自 `ModbusTcpDriver`
- **关键依赖**：`NewLife.IoT`（IDriver 标准）、`NewLife.Modbus`（Modbus TCP 实现）

### DRV-2 连接节点（SchneiderNode）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderNode.cs`
- **接口**：`INode`（来自 NewLife.IoT）
- **属性**：
  - `Address`：主机地址
  - `Driver`：关联的驱动实例
  - `Device`：关联的设备信息
  - `Parameter`：连接参数

### DRV-3 连接参数（SchneiderParameter）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderParameter.cs`
- **基类**：`ModbusTcpParameter`（来自 NewLife.Modbus）
- **继承的关键参数**：Host（站号）、Server（地址）、ReadCode（读功能码）、WriteCode（写功能码）等

### PRT-2 施耐德地址解析

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderAddress.cs`
- **核心类型**：`SchneiderAddressType`（枚举）、`SchneiderAddress`（解析结果类）
- **功能**：
  - `SchneiderAddress.Parse("%MW100")` → (HoldingRegister, offset=100, isBit=false)
  - `SchneiderAddress.Parse("%M0.1")` → (Coil, offset=0, isBit=true, bitIndex=1)
  - `SchneiderAddress.Parse("%I0.0")` → (DiscreteInput, offset=0, isBit=true, bitIndex=0)
  - `SchneiderAddress.Parse("%QW50")` → (HoldingRegister, offset=50, isBit=false)
- **施耐德→Modbus 映射规则**：
  - `%M` / `%Mx.y` → Modbus 线圈 (FC01/FC05/FC15)
  - `%I` / `%Ix.y` → Modbus 离散输入 (FC02)
  - `%MW` → Modbus 保持寄存器 (FC03/FC06/FC16)
  - `%IW` → Modbus 输入寄存器 (FC04)
  - `%MD` → Modbus 保持寄存器 x2 (32位双字)
  - `%MF` → Modbus 保持寄存器 x2 (32位浮点)
  - `%QW` → Modbus 保持寄存器 (FC16)
  - `%SW` → Modbus 输入寄存器 (FC04，系统字)

### PRT-3 型号预设配置

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderModel.cs`
- **核心类型**：`SchneiderModel`（枚举）、`SchneiderModelInfo`（预设信息）
- **功能**：
  - `SchneiderModelHelper.GetModelInfo(SchneiderModel)` 返回型号预填参数
  - `SchneiderDriver.CreateParameter(SchneiderModel)` 创建预填的驱动参数
- **预设信息**：型号名称、默认端口、推荐功能码、最大线圈数、最大寄存器数、备注

### PRT-4 标签式读写 API

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderDriver.cs`
- **新增方法**：
  - `ReadTag(INode, String, CancellationToken)` — 读取单个施耐德标签
  - `WriteTag(INode, String, Object, CancellationToken)` — 写入单个施耐德标签
  - `ReadTags(INode, String[], CancellationToken)` — 批量读取施耐德标签
- **内部流程**：解析标签地址 → 确定功能码与地址 → 调用基类 ReadAsync/WriteAsync

### TST-1 手动测试控制台

- **代码位置**：`Test/Program.cs`
- **功能**：支持两种模式
  - 读写模式：输入整数值写入 PLC 地址，然后读取验证
  - 循环读模式：每秒读取一次 PLC 地址并在控制台输出
- **依赖**：NewLife.Schneider、NewLife.IoT
