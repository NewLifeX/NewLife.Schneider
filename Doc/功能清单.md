## 详细说明

### DRV-1 驱动入口（SchneiderDriver）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderDriver.cs`
- **基类**：`ModbusTcpDriver`（来自 NewLife.Modbus）
- **接口实现**：`ILogFeature`、`ITracerFeature`
- **核心行为**：
  - 通过 `[Driver("SchneiderPLC")]` 支持驱动自动发现
  - 重写 `Open()`：调用基类打开 Modbus TCP 连接后，额外调用 `Modbus.Open()` 初始化通道
  - 读写操作继承自 `ModbusTcpDriver`，支持 Modbus 标准功能码
  - 关闭操作继承自 `ModbusTcpDriver`
- **关键依赖**：`NewLife.IoT`（IDriver 标准）、`NewLife.Modbus`（Modbus TCP 实现）

### DRV-2 连接节点（SchneiderNode）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderNode.cs`
- **接口**：`INode`（来自 NewLife.IoT）
- **属性**：
  - `Address`：主机地址
  - `Driver`：关联的驱动实例
  - `Device`：关联的设备信息
  - `Parameter`：连接参数

### DRV-3 连接参数（SchneiderParameter）

- **代码位置**：`NewLife.Schneider/Drivers/SchneiderParameter.cs`
- **基类**：`ModbusTcpParameter`（来自 NewLife.Modbus）
- **继承的关键参数**：Host（站号）、Server（地址）、ReadCode（读功能码）、WriteCode（写功能码）等

### TST-1 手动测试控制台

- **代码位置**：`Test/Program.cs`
- **功能**：支持两种模式
  - 读写模式：输入整数值写入 PLC 地址，然后读取验证
  - 循环读模式：每秒读取一次 PLC 地址并在控制台输出
- **依赖**：NewLife.Schneider、NewLife.IoT
